# Примеры диаграмм и графиков Mermaid для VS Code

В этом файле собраны основные типы диаграмм, которые поддерживает встроенный плагин Markdown / Mermaid в VS Code.

## 1. Блок-схема (Flowchart)
Используется для визуализации алгоритмов, бизнес-процессов и логических цепочек.

```mermaid
flowchart TD
    A[Старт] --> B{Есть данные?}
    B -- Да --> C[Обработка данных]
    B -- Нет --> D[Запрос данных]
    D --> C
    C --> E((Финиш))
    
    subgraph Легенда
        A
        E
    end
```

## 2. Диаграмма последовательности (Sequence Diagram)
Отлично подходит для отображения взаимодействия между объектами или микросервисами во времени.

```mermaid
sequence diagram
    autonumber
    Клиент->>Сервер: API-запрос (Данные формы)
    activate Сервер
    Сервер->>База Данных: SELECT * FROM users
    activate База Данных
    База Данных-->>Сервер: Результат выборки
    deactivate База Данных
    Сервер-->>Клиент: HTTP 200 OK (JSON)
    deactivate Сервер
```

## 3. Диаграмма Ганта (Gantt Chart)
Используется для управления проектами и планирования задач по времени.

```mermaid
gantt
    title План разработки модуля
    dateFormat  YYYY-MM-DD
    section Проектирование
    Анализ требований           :active, des1, 2026-10-01, 5d
    Архитектура БД              :        des2, after des1, 3d
    section Разработка
    Написание API               :crit, active, dev1, after des2, 7d
    Фронтенд-компоненты         :dev2, after des2, 5d
    section Тестирование
    QA-тесты                    :test1, after dev1, 4d
```

## 4. Класс-диаграмма (Class Diagram)
Полезна для объектно-ориентированного проектирования и архитектуры кода.

```mermaid
classDiagram
    class Animal {
        +String name
        +int age
        +makeSound()*
    }
    class Dog {
        +String breed
        +makeSound()
        -wagTail()
    }
    class Cat {
        +Boolean isLazy
        +makeSound()
    }
    Animal <|-- Dog : Наследование
    Animal <|-- Cat
```

## 5. Диаграмма состояний (State Diagram)
Показывает жизненный цикл объекта или системы и переходы между состояниями.

```mermaid
stateDiagram-v2
    [*] --> Черновик
    Черновик --> На_модерации : Отправить
    На_модерации --> Опубликовано : Одобрить
    На_модерации --> Черновик : Отклонить
    Опубликовано --> В_архиве : Удалить
    В_архиве --> [*]
```

## 6. Диаграмма сущностей и связей (ER-Diagram)
Используется для проектирования схем баз данных.

```mermaid
erDiagram
    CUSTOMER ||--o{ ORDER : places
    ORDER ||--|{ LINE-ITEM : contains
    CUSTOMER {
        string name
        string email
    }
    ORDER {
        int orderNumber
        date dateCreated
    }
```

## 7. Круговая диаграмма (Pie Chart)
Простой способ показать процентное соотношение долей.

```mermaid
pie title Распределение бюджета проекта
    "Разработка" : 50
    "Маркетинг" : 25
    "Тестирование" : 15
    "Менеджмент" : 10
```

## 8. Квадрант-графы (Quadrant Chart)
Используется для матричного анализа (например, важность/срочность).

```mermaid
quadrantChart
    title Анализ фич (Ценность vs Сложность)
    x-axis Низкая сложность --> Высокая сложность
    y-axis Низкая ценность --> Высокая ценность
    quadrant-1 Сделать позже
    quadrant-2 Сделать в первую очередь
    quadrant-3 Не делать
    quadrant-4 Стратегические задачи
    Фича А: [0.3, 0.8]
    Фича Б: [0.7, 0.2]
    Фича В: [0.2, 0.3]
    Фича Г: [0.8, 0.9]
```

## 9. Ментальная карта (Mindmap)
Позволяет структурировать идеи или дерево категорий.

```mermaid
mindmap
  root((Разработка ПО))
    Тестирование
      Автоматизация
      Ручное
    Фронтенд
      Vue.js
      React
    Бэкенд
      Python
      Node.js
```

## 10. Хронология / Таймлайн (Timeline)
Отличный инструмент для отображения исторических событий или дорожных карт.

```mermaid
timeline
    title Эволюция веб-технологий
    1991 : Появление WWW : HTML
    1995 : JavaScript : PHP
    2015 : ES6 : Популярность React
    2026 : ИИ-ассистенты в разработке
```
