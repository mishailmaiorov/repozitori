## Основы Bash CLI

**Bash** - терминал, командная строка, консоль. Еще **Bash** - это скриптовый ЯП

### Терминал

Сдвинуть вверх лог ранее команд
```shell
clear
```
Сбросить текущий терминал
```shell
reset
```

Получить историю всех ранее введенных команд
```shell
history
```
Выполнить команду по её порядковому номеру
```shell
!53
```
где 53 - это порядковый № команды из списка `history`
```shell
!!
```
Перелистывание ранее введенных команд
`стрелки вверх/вниз^v`

Дописывание команд и имен файлов/каталогов при помощи `Tab`

### Linux

Получить информацию по дистрибутиву
```shell
`lsb_release -a`
```
или красивей
```shell
fastfech
```
или технические подробности
```shell
inxi -F
```
Системный монитор
```shell
htop
```

Получить t и CPU/GPU и скорость вращения Fan
```shell
sensors
-
Получить id текущего пользователя
```shell
id
```
Получить список групп, в которых числится текущий пользователь
```shell
groups
```

#### Софт

Показать календарь
```shell
cal
```
Получить дату и время
```shell
date
```
Получить содержимое текстового файла
```shell
cat имя_файла
```
Отредактировать текстовый файл
```shell
nano имя_файла
```
Получить имя компьютера
```shell
hostname
```
Получить текущий `ip` компьютера
```shell
hostname -i
```
Информация по сети
```shell
infconfig
```
или
```shell
ip -c r
```
или
```shell
ip -c a
```
Пинг адреса
```shell
Ping 8.8.8.8
```
```shell
Ping ya.ru
```
Чтобы выйти из бесконечного пинга, выполните `Ctrl+C`

Выполнить пинг указанное кол-во раз
```shell
ping -c 4 ya.ru
```
Получить ин-фу по указанному домену
```shell
whoils ozon.ru
```
Получить список портов
```shell
netstat -an
```
Получить маршруты
```shell
route
```
